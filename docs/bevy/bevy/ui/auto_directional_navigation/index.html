Module auto_directional_navigation

An automatic directional navigation system, powered by the AutoDirectionalNavigation component.

AutoDirectionalNavigator expands on the manual directional navigation system provided by the DirectionalNavigation system parameter from bevy_input_focus.

AutoDirectionalNavigation

AutoDirectionalNavigator
A system parameter for combining manual and auto navigation between focusable entities in a directional way. This wraps the DirectionalNavigation system parameter provided by bevy_input_focus and augments it with auto directional navigation. To use, the DirectionalNavigationPlugin must be added to the app.
